# Shard

A WebGPU-first 2D/3D game engine in TypeScript, built for AI-driven authoring.

Early development. See [VISION.md](VISION.md) for what this is and [specs/ROADMAP.md](specs/ROADMAP.md)
for where it's going.

```sh
pnpm install
pnpm playground   # browser sandbox at http://localhost:5180
pnpm studio       # desktop app (Tauri)
```
