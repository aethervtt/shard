# Generators

Generated by `shard docs`. A generator is `(seed, params) → output`, cached by the hash of its
inputs (name, version, code, params, seed, loaded assets). Use an output as:

- a file, `generators/<name>.gen.json` (schema `.shard/schemas/gen.schema.json`), usable anywhere a
  handle of the output type is: `{ "path": "generators/boulder.gen.json" }`
- a ref, `{ "path": "procedural:<generator>?radius=2&seed=3" }` (numbers, bools, asset paths)
- entities: `procgen/GeneratorInstance { "generator": { "path": "<generator>" }, "seed": 3, "params": {} }`
- at runtime: `await generate(world, Gen, params, seed)`

Tune one with MCP `preview_generator { "generator": "<name>", "seeds": "1-9" }` (a contact sheet)
and `run_generator` (counts, bounds, cache key). See `.agents/skills/make-a-generator.md`.

## `star-explorer/AsteroidField`

Boulders scattered in a shell around the instance, each a Rock output.

Output: `Prefab`. Version 1.

| Param | Type | Default | Range | Description |
|---|---|---|---|---|
| `count` | integer | `12` | ≥ 1, ≤ 256 | How many rocks. |
| `radius` | number | `20` | ≥ 0, m | Shell radius. |
| `spread` | number | `6` | ≥ 0, m | Shell thickness. |
| `size` | number[2] | `[0.4,1.6]` |  | Rock radius range [min, max]. |
| `material` | null or Material ref | `null` |  | The rocks’ material. |

```json
{"$schema":"../.shard/schemas/gen.schema.json","generator":"star-explorer/AsteroidField","seed":1,"params":{}}
```

## `star-explorer/Rock`

A boulder: an icosphere displaced along its normals by a noise graph.

Output: `Mesh` (sub-assets `#LOD1`, … when it makes levels of detail). Version 1.

| Param | Type | Default | Range | Description |
|---|---|---|---|---|
| `radius` | number | `1` | ≥ 0.05, m | Size before displacement. |
| `roughness` | number | `0.3` | ≥ 0, ≤ 1 | How far the noise pushes the surface, as a fraction of the radius. |
| `detail` | integer | `3` | ≥ 0, ≤ 6 | Icosphere subdivisions. |
| `shape` | null or NoiseGraph ref | `{"path":"assets/noise/rock.noise.json"}` |  | Displacement noise, sampled on the unit sphere. |

```json
{"$schema":"../.shard/schemas/gen.schema.json","generator":"star-explorer/Rock","seed":1,"params":{}}
```
