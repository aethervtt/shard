# Assets

Generated by `shard docs`. Files under the asset roots (`assetRoots` in shard.json) are imported
by extension. Each gets a `.meta` next to it with its guid and import settings; commit both.
Reference assets in scenes by path: `{ "path": "materials/hull.material.json" }`, or a
sub-asset with `#`: `{ "path": "assets/ship.glb#Mesh/Hull" }`.

## `data/material`

Files: `*.material.json`

No import settings.

## `texture`

Files: `*.png`, `*.jpg`, `*.jpeg`, `*.webp`, `*.hdr`, `*.ktx2`

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `usage` | `"color"` \| `"data"` \| `"normal"` \| `"hdr"` | `"color"` |  | color: sRGB albedo/emissive. data: linear masks (roughness, metallic, AO). normal: tangent-space normal map. hdr: linear float (environment maps). |
| `mipmaps` | boolean | `true` |  | Generate a full mip chain. |
| `compression` | `"none"` \| `"etc1s"` \| `"uastc"` | `"none"` |  | Basis Universal. uastc: high quality, larger. etc1s: small, lossy. Encoding takes seconds per texture on first import; the cache keeps the result. |
| `maxSize` | integer | `4096` | ≥ 1, ≤ 16384 | Downscale larger images. |
| `flipY` | boolean | `false` |  | Flip vertically on import. |
| `premultiplyAlpha` | boolean | `false` |  | Multiply color by alpha on import. |

## `gltf`

Files: `*.gltf`, `*.glb`

| Setting | Type | Default | Range | Description |
|---|---|---|---|---|
| `scale` | number | `1` | ≥ 0 | Uniform scale applied to the model root (0.01 for centimeter files). |
| `forward` | `"+z"` \| `"-z"` | `"+z"` |  | Which way the model faces after import. "+z" keeps the file as authored (glTF models face +Z); "-z" turns it around to face Shard's forward, the way ships fly. |
| `emissiveLuminance` | number | `1000` | ≥ 0, cd/m² | Luminance of emissiveFactor 1 at strength 1 (glTF emission has no unit). |
| `cameras` | boolean | `false` |  | Spawn the file's cameras. |
| `lights` | boolean | `false` |  | Spawn the file's lights (KHR_lights_punctual). |
| `generateNormals` | `"missing"` \| `"always"` \| `"never"` | `"missing"` |  | Flat normals for primitives without them ("missing"), for all, or never. |
