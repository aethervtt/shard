## Default Permission

What a Shard game needs: its data's base URL, its saves, and its server sidecar.

#### This default permission set includes the following:

- `allow-base`
- `allow-storage-read`
- `allow-storage-write`
- `allow-storage-list`
- `allow-storage-delete`
- `allow-server-start`
- `allow-server-stop`
